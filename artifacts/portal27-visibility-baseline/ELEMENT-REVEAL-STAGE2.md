# 收筆到屬性形成：第二階段流程預覽

## 入口與操作

設定 → 特效 → 屬性揭曉樣板 → **預覽收筆到屬性**。

1. 選擇火、水、風、土、光或暗，在畫面中拖曳畫線。
2. 放開後保留筆跡 1.2 秒，光帶內部繼續流動；這段時間再次碰觸即可續畫。最後 0.36 秒外圍霧與白點先向內蓄力。
3. 整條光帶快速化成魔力球，與外圍霧、白點一起向外爆散，在慢動作中拉開前後深度，再一起加速吸回中央；魔力球逐漸帶上屬性色。
4. 共用原本六屬性材質，從匯聚區逐步形成；後半段淡入屬性名稱。
5. 最後保留低亮度材質與名稱，可暫停、切換屬性或按「重新畫一次」。

「預覽六種屬性」仍是獨立循環材質樣板。主鑑定入口與既有特效預覽仍可持續試畫。

## 演出時間

| 階段 | 時間 | 行為 |
| --- | --- | --- |
| 繪製 | 由使用者決定 | 按住不自動進入揭曉。累積至少 24 CSS px 的有效移動後，放開才開始等待。 |
| 等待 | 1.2 秒 | 筆跡保留且持續流動；最後 0.36 秒外圍內縮 26%。再碰觸取消倒數並平順退回外圈。 |
| 爆散與收束 | 2.1 秒 | 魔力球、外圍霧與白點共同展開，持續慢漂，收束前再向外推一小段，各自轉入加速吸回；全部在 2.1 秒內接上材質。 |
| 形成 | 0.8 秒 | 火由下往上點燃、水由中央形成圓形水團，其餘屬性使用同一套材質與適合的展開遮罩。 |
| 展開 | 1.8 秒 | 展示材質動態，後半段淡入名稱。 |
| 餘韻 | 0.8 秒 | 材質降低至 45% 強度，留下名稱；完成後保持畫面。 |

共約 6.7 秒。這一階段的最後一段是「餘韻」，尚未接正式階級、魔力值與結果卡；畫面不產生示範用的假結果。

### 魔力球的空間與張力

- 魔力球沿整條可見筆跡取樣，約 115 ms 內完成連續光帶與球體的交接，不再顯示切開的小線段。
- 爆散目的地固定圍繞畫面中心，360 度均勻分配角度與不同半徑。橫線、直線或亂畫只影響起點，不影響最後的近圓形分布；外圈半徑為畫面短邊的 94%，可自然超出螢幕。
- 一般有效筆跡至少約 72 顆球，長筆跡最多 180 顆。約 16% 的球位於近景，有更大的尺寸與寬柔焦；遠景球較小、較淡。位置與尺寸共用透視深度，球體按遠到近繪製。
- 展開採連續速度曲線，從靜止加速、再逐漸減速；達到外圍時仍沿各自方向持續漂移，沒有全體停住的瞬間。
- 每顆球都有獨立的展開時間、角速度、外推時機與回收時間。近景另帶較快的視差移動，深度不只靠大小區分。
- 收束前各自再向外推約 8～14%，期間持續飄動；接著沿彎曲路徑加速吸回。吸回路徑承接當下的漂移速度，保持位置與速度連續。
- 爆散中心與材質形成位置分開：爆散永遠以畫面中心為準，吸回終點則承接該屬性的材質位置。
- 光尾沿球體實際走過的曲線產生，慢漂時幾乎沒有，快速吸回時拉長；球體靠近中心時縮小、淡出。
- 使用一般透明合成、限制球體總數，避免中心疊成白色光團。畫面邊緣的球可自然越界，不排成方框。

此預覽用移動距離判斷是否畫線，方便快速比較，不採正式流程規劃中尚待調整的「有效滑動約 2 秒」門檻。

### 外圍環境與停筆動畫

- 沿用當下的霧、白點與設定，從它們所在的位置內縮，沒有另外疊一圈替身。既有星芒若已開啟，也會跟著收放。
- 等待最後 0.36 秒內縮約 26%，接著與魔力球一起打開成以畫面中心為主的圓形空間；保留各自速度與轉向時間。
- 魔力球吸回時，霧與白點同步沿彎曲路徑收回材質形成位置。霧先縮小、減淡，避免中心累積成過亮光團；材質出現後外圈保持收起。
- 續畫會取消蓄力並平順釋放壓力，重畫或切換屬性則回到完整待機外圈。
- 筆跡的流動時間與淡出時間分開：等待只保留筆跡壽命，能量亮段、霧絲與星塵持續運動。只有明確暫停或頁面隱藏才停止整個畫面。
- 正式流程接入時沿用此共用繪圖與保留 API，不能再用凍結整個軌跡時間的方式保留筆跡。

## 實作界線

- `js/reveal-flow.js`：純狀態與時間控制，沒有 DOM、計時器、亂數或正式結果存取。
- `js/reveal-gather.js`：獨立的可見筆跡快照；魔力球爆散、透視深度、慢漂、曲線吸回與漸變色。最多 1,600 路徑點、180 顆魔力球，使用 source-over 合成並在中心前淡出。
- `js/reveal-atmosphere.js`：純視覺的外圍內縮、爆散與旋入動作；讀取現有粒子座標，不改動池、設定或鑑定結果。
- `js/element-material-renderer.js`：可接受流程指定的時間、phase、透明度與形成進度。獨立材質樣板仍沿用原本循環。
- `js/portal-scene.js`：可選的粒子座標轉換與 `holdTrails`。等待保留筆跡時仍推進流動；真正凍結僅用於已交棒的筆跡。
- `js/finger-trails.js`、`js/ribbon-renderer.js`：分開管理流動時間與淡出時間，未指定保留時維持原本效果。
- `index.html`：預覽入口、手指事件分派、控制列、名稱與既有單一 RAF 整合。
- 流程採用目前特效設定；只在預覽內確保軌跡啟用、停留至少 1.3 秒，沒有寫回個人設定。

## 生命週期

- 收束開始後鎖定畫線，避免演出途中插入新筆。
- 多指觸控只認領第一個指標；取消、失去擷取、視窗失焦會安全釋放。
- 隱藏分頁停止推進；若仍在等待，取消倒數，回來後可續畫。已進入收束的演出則從原進度接續。
- 暫停會凍結整個畫面；重畫、切換屬性及返回設定會清除上一段流程。
- WebGL 不可用時顯示錯誤訊息，仍可返回設定；context 恢復後重新建立繪圖資源。
- 預覽沒有抽選或修改 Session 結果，正式結果接入留在第三階段。

## 驗證

- `node tests/reveal-flow.cjs`：六種屬性、門檻、續畫、取消、多指、暫停、階段邊界與時間上限。
- `node tests/reveal-gather.cjs`：筆跡快照不變性、球體與路徑資源上限、橫線／直線／亂畫的圓形與中心分布、深度、持續漂移、收束前外推、個別速度、速度連續性、重複繪製一致性及有效座標。
- `node tests/reveal-atmosphere.cjs`：預收束、爆散銜接、續畫回復、圓形分布、慢漂、再次外推、逐顆異速、目標淡出、暫停一致性與視窗縮放。
- `node tests/ribbon-parity.cjs`：核准的光帶畫法逐像素比較；停筆等待仍持續流動、保留壽命、恢復淡出與真正暫停。
- `node tests/stage1.cjs`：真實頁面程式的預覽整合、輸入鎖定、分頁暫停、返回、設定與抽選隔離。
- `node tests/portal-scene.cjs`：主互動既有速度、背景、粒子與手指行為。
- `node tests/reveal-flow-browser.cjs`：桌面 Chrome 真實 pointer 與 WebGL；檢查放開後光帶本身的像素持續變動，等待／爆散／慢漂／吸回／形成／展開截圖，暫停像素一致、六種完整播放、手機尺寸控制列、重畫及返回主互動。

這些是程式與桌面瀏覽器檢查；iPhone PWA 的質感、節奏與流暢度仍由使用者驗收。

產物：`artifacts/reveal-flow-stage2.png`、`artifacts/reveal-flow-phone-ui.png`；三種筆跡的正式收束繪圖層對照：`artifacts/gather-round-burst.png`。
